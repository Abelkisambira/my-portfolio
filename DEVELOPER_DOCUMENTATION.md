# Ergon Designs Developer Documentation

## Project Overview

Ergon Designs is a responsive portfolio website for an interior and landscape studio. The site showcases services, project highlights, and a contact form for client inquiries.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Tailwind CSS via CDN
- Supabase for database-backed inquiries
- Resend for outbound email notifications
- Local browser storage fallback for temporary submissions

## Project Structure

- index.html - main page structure and content
- css/ - site styling and component styles
- js/ - JavaScript behavior for modal, menu, form submission, and interactions
- assets/ - images and media files
- tailwind/ - Tailwind config
- DEVELOPER_DOCUMENTATION.md - project documentation

## Core Features

- Responsive navigation for desktop and mobile
- Hero section with CTA and animated stats
- Services overview
- Portfolio project cards with modal preview gallery
- Contact form with validation and submission handling
- Scroll reveal and hover animations

## Contact Form Flow

The contact form currently supports a layered submission flow:

1. Validate name, email, and message
2. Build a new inquiry payload
3. Attempt submission to Supabase if environment variables are configured
4. Fall back to local browser storage if Supabase is not configured
5. Open the default mail client as a backup when local fallback is used

## Supabase Setup

### 1. Create a Supabase Project

- Go to https://supabase.com
- Create a new project
- Copy the Project URL and anon key

### 2. Configure Frontend Values

Update the values in index.html:

- ERGON_SUPABASE_URL
- ERGON_SUPABASE_ANON_KEY

Example:

```js
window.ERGON_SUPABASE_URL = 'https://xyzcompany.supabase.co';
window.ERGON_SUPABASE_ANON_KEY = 'your-anon-key';
```

### 3. Create a Database Table

Create a table named inquiries with the following columns:

- id: uuid, default value generated by database
- name: text
- email: text
- message: text
- submitted_at: timestamp with time zone

Example SQL:

```sql
create table public.inquiries (
  id uuid default gen_random_uuid() primary key,
  name text not null,
  email text not null,
  message text not null,
  submitted_at timestamptz default now()
);
```

### 4. Enable Row Level Security

For initial simplicity, allow inserting rows anonymously if you want the public form to work without authentication.

Example policy:

```sql
create policy "Allow public inserts"
on public.inquiries
for insert
with check (true);
```

## Resend Setup

Resend is recommended for sending admin emails when a new inquiry arrives.

### Recommended Flow

- Use Supabase Edge Function or backend endpoint to receive the inquiry
- Trigger Resend to send a notification email to the studio inbox
- Optionally send a confirmation email to the client

### Basic email flow

- Sender: noreply@yourdomain.com
- Recipient: contact@ergondesigns.com
- Subject: New inquiry from <name>
- Body: name, email, project message

## Environment and Secrets

Keep secrets out of the frontend. The frontend should only use public Supabase values for anon access. For production email dispatch, prefer a secure backend or Supabase Edge Function.

## Local Development

Use any static file server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
